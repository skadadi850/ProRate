# ProRate

Protein backbone tokenization by rate-distortion segmentation.

ProRate turns a protein backbone into a short sequence of integers and rebuilds the backbone from those integers alone. Each chain is
split into variable-length fragments by a dynamic program that minimizes fragment error, a fitted boundary error and a rate penalty
weighted by a single multiplier lambda. Fragments are drawn from length-specific codebooks of observed backbone fragments, and adjacent
fragments are joined by six boundary coordinates quantized in a closed loop. There is no neural network and no learned decoder: decoding is
forward kinematics. Lowering lambda moves the tokenizer smoothly along the rate-distortion curve.

This repository contains the code, the released checkpoints' loader, and the scripts that reproduce the reconstruction results and figures
of the paper (CAMEO and CASP14). Data, checkpoints and cached results of the other methods are distributed as one archive on Zenodo.

## Results

Reconstruction of the CAMEO and CASP14 test chains from the integer stream alone (backbone RMSD in angstroms, bits per residue includes the
amortized codebook).

| Model | Bits per residue | RMSD CAMEO | RMSD CASP14 |
|---|---|---|---|
| ProRate (free), lambda 0.4 | 8.58 | 0.332 | 0.335 |
| ProRate (free), lambda 0.06 | 20.22 | 0.116 | 0.117 |
| ProRate (free), lambda 0.015 | 39.54 | 0.062 | 0.065 |
| ProRate (valid), lambda 0.06 | 36.22 | 0.355 | 0.363 |

"Valid" keeps the peptide-link geometry (CA-C-N, C-N-CA and omega) within 2 sigma of the reference link where the grid permits.
Full tables, comparisons with GeoBPE, ProToken, AminoAseed, ESM3 and VQ-VAE, and all figures are in the paper and are regenerated by
`run.sh`.

## Quick start

```bash
git clone https://github.com/skadadi850/ProRate.git
cd prorate
pip install -r requirements.txt
conda install -c conda-forge pymol-open-source
bash download.sh        # downloads, verifies and unpacks release/ (Zenodo)
bash run.sh             # evaluates the seven checkpoints and writes the figures to outputs/
```

`run.sh` takes about 35 minutes on one RTX 4090. Per-arm results are written to `outputs/eval/<arm>/eval.json`, the figures to
`outputs/`, and logs to `logs/`.

To retrain a codebook:

```bash
bash train.sh protrig_s8k_rw0p06_link3_s1
```

## Other methods

GeoBPE, ProToken, AminoAseed, ESM3 and VQ-VAE are not rerun by this repository. Their results are read from `release/cache/`. We measured
ProToken, AminoAseed and GeoBPE (K=600) on the same test chains; the remaining points are taken from published results. The details are
in [readme_detailed.md](readme_detailed.md).
